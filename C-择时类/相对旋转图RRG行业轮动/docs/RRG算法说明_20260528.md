# RRG 算法说明（factor_algo.py）

> 模块：`src/factor_algo.py`
> 研报来源：西部证券 2026-05-25《指数化配置系列研究（6）：相对旋转图 RRG 框架下的行业研究》（冯佳睿 / 陈曼莲）

`factor_algo.py` 是一组**纯函数**（DataFrame in / DataFrame out，无 I/O、无 qlib/DolphinDB 依赖；唯一例外是 `compute_rs` 的日历兜底），实现 JdK 比率法 RRG 与两版扩散指标。

---

## 1. 核心概念

RRG（Relative Rotation Graph，相对旋转图）用两个相互正交的指标刻画一个标的相对基准的**位置**与**动量**：

| 指标 | 含义 | 中枢 |
|------|------|------|
| **RS-Ratio**（X 轴） | 相对强度的趋势——标的当前相对强度 vs 一段时间前的相对强度 | **100** |
| **RS-Momentum**（Y 轴） | RS-Ratio 自身的变化率——领先于 RS-Ratio 的拐点 | **100** |

二者在 (100, 100) 的十字中枢上构成四象限，描述行业在轮动周期中所处的阶段。

### ⚠️ 比率法 ≠ 差值法（第一铁律）

本模块复现的是 **Julius de Kempenaer 原版比率法**：

```
RS-Ratio = MA_smooth( 100 × RS_t / RS_{t-T} )        中枢 = 100
```

而**不是**国信莫尼塔 2018 的差值法（`short_MA(ratio) − long_MA(ratio)`，中枢 0）。
若要修改 `compute_rs_ratio` / `compute_rs_momentum` 的公式形态，先重读研报第一节——
中枢 100 是贯穿全模块（含 `classify_quadrant`、绘图层 `center=(100,100)`）的不变量。

## 2. 公式推导

### 2.1 共享算子 `_smooth_ratio_shift`

RRG 三个层级（RS → RS-Ratio → RS-Momentum）都是「同一个比率-平滑算子」的递归套用，因此抽取为单一私有算子，保证公式只在一处落地、避免多份实现漂移：

```python
_smooth_ratio_shift(x, lookback, smooth) = MA_smooth( 100 × x / x.shift(lookback) )
```

即 `(100.0 * x / x.shift(lookback)).rolling(window=smooth).mean()`。

### 2.2 三层递推

| 层级 | 公式 | 代码 |
|------|------|------|
| **RS**（相对强度） | `RS = price / benchmark × 100` | `compute_rs` |
| **RS-Ratio** | `_smooth_ratio_shift(RS, lookback_ratio, smooth)` | `compute_rs_ratio` |
| **RS-Momentum** | `_smooth_ratio_shift(RS-Ratio, lookback_mom, smooth)` | `compute_rs_momentum` |

> **基准（benchmark）的选择**：研报 §2.1 以「中信一级行业等权**组合**（剔除综合、综合金融）」
> 为基准（`equal_weight_benchmark`，各行业日收益等权累乘成 NAV），**不是**中证 1000 等外部宽基。
> RS-Ratio 仅依赖基准的收益比、对其绝对水平**尺度不变**，故等权组合 NAV（首日=1.0）即可。
> 数据层 `fetch_rrg_dataset(benchmark_code="ind_avg")` 已封装此构造（默认口径）；传外部指数代码
> 则用外部指数为基准。

默认参数（研报口径）：

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `lookback` / `lookback_ratio` | 220 | RS 比率回看天数（约一年交易日） |
| `lookback_mom` | 60 | RS-Ratio 比率回看天数（约一季） |
| `smooth_window` | 20 | MA 平滑窗口（约一月） |

> `compute_rrg` 一次性返回 `(RS-Ratio, RS-Momentum)`，内部复用中间 `RS-Ratio` 避免重复计算——推荐入口。

## 3. NaN warm-up 精确行数（第二铁律）

比率（`shift`）与平滑（`rolling`）会在序列头部产生确定行数的 NaN。**公式错一点就会静默全 NaN**，务必精确：

| 函数 | warm-up NaN 行数 | 默认值 | 首个有效行 |
|------|-----------------|--------|-----------|
| `compute_rs_ratio` | `lookback + smooth_window − 1` | 239 | 第 240 行 |
| `compute_rs_momentum` / `compute_rrg` | `lookback_ratio + lookback_mom + 2·(smooth_window − 1)` | 318 | 第 319 行 |
| `diffusion_count_ratio` / `diffusion_value_weighted` | `lookback + smooth_window − 1` | 239 | 第 240 行 |

长度校验下界（低于此抛 `ValueError`）：

- `compute_rs_ratio`：`lookback + smooth_window`（默认 240）
- `compute_rs_momentum` / `compute_rrg`：`lookback_ratio + lookback_mom + 2·(smooth_window − 1) + 1`（默认 319）

> RS-Momentum 经过**两次** `shift+rolling`，所以是 `2·(smooth_window − 1)` 而非 `smooth_window`。
> 历史上曾误写成 `+ smooth_window`（= 300），漏算第二层 rolling 各自吃掉的 `smooth_window − 1` 行，导致 300–318 行输入静默全 NaN——已修（commit `75fac04` / `ce0b09c`），勿走回头路。

## 4. 数据契约

| 参数 | 形态 |
|------|------|
| `price` / `close` | `pd.DataFrame`，index=date，columns=industry_code 或 stock_code |
| `benchmark` | `pd.Series` 或单列 `pd.DataFrame`（内部 `iloc[:,0]` 转 Series） |
| `membership` | `pd.DataFrame`，index=date，columns=stock_code，**value=industry_name (str) 或 NaN**——时变格式，自动支持成分股调入调出 |
| `free_float_mv` | `pd.DataFrame`，index=date，columns=stock_code，value=自由流通市值（元） |

**返回**：RRG 函数输出 **index = benchmark.index**，columns = price.columns；扩散函数输出 index=date, columns=industry。

### 调用者职责（第三铁律）

`compute_rs` 主体是纯函数，但调用者负责：
1. **日历对齐**——price 与 benchmark 覆盖同一交易日历；
2. **价格严格为正**——含 0 / 负值会产生 inf/NaN 并经下游 rolling 传播；
3. **处理停牌空值**——price 自身 index 上的停牌 NaN **不会**被算法层兜底，应在传入前 ffill。

### 算法层日历兜底（`compute_rs`，2026-05-27 引入）

当 `benchmark.index` 含 `price.index` 没有的交易日（典型如行业指数 ETL 漏跑某几天）时，`compute_rs`：
- `warnings.warn(UserWarning)`，含缺失天数与前 5 个缺失日；
- **自动对整张 `price` `reindex + ffill` 兜底**——避免散落缺日被 `shift(lookback)` + `rolling(smooth)` 双层放大约 `2 × smooth_window` 倍。

行为约定：
- **无差异场景**：与纯 `reindex` 字节级一致，原有调用方零影响。
- **有差异场景**：触发兜底时 price 原有的 NaN 也会被一并 ffill；若需保留停牌 NaN 语义，调用方应在传入前自行 `reindex + ffill`。
- **限制**：ffill 救不了 price 头部**连续**缺日（无前值可填），这种情况仍保留 NaN，warm-up 加长。

实证：969 日 benchmark + industry 缺 11 个中段日 → 不 ffill 时 `rs_mom` NaN 占比 ≈ 33%（warm-up）+ 22%（缺日经双层扩散）= 55%；自动 ffill 后回到 33%（仅 warm-up）。

## 5. 四象限分类 `classify_quadrant`

按研报象限定义把 `(RS-Ratio, RS-Momentum)` 映射为 1/2/3/4：

| 编号 | 条件 | 研报用语 | 英文 |
|------|------|---------|------|
| **1** | RS-Ratio > 100 且 RS-Mom > 100 | **领先** | leading |
| **2** | RS-Ratio < 100 且 RS-Mom > 100 | **改善** | improving |
| **3** | RS-Ratio < 100 且 RS-Mom < 100 | **滞后** | lagging |
| **4** | RS-Ratio > 100 且 RS-Mom < 100 | **疲软** | weakening |

- 任一值为 NaN 或**恰为 100**（落在中心轴上）→ 返回 NaN，不强行归边。
- 严格不等号（`>` / `<`），与绘图层象限着色 / tooltip 趋势判定**同语义**。
- `rs_ratio.columns` 与 `rs_mom.columns` 不一致时抛 `ValueError`（避免静默生成幻列）；行索引可不同，内部 `align(axis=0)` 对齐。

> 术语铁律：统一使用研报正用语「领先 / 改善 / 滞后 / 疲软」，**不要**用旧译「领涨 / 走强 / 领跌 / 走弱」（commit `238c774` 已清理术语污染）。

## 6. 扩散指标

衡量**行业内部**有多少成分股处于上涨状态，是 RRG 的补充视角。两版共享「上涨判定 + 行业聚合 + MA 平滑」骨架，差别在权重：

### 6.1 `diffusion_count_ratio`（数量占比）

```
扩散 = MA_smooth( 行业内上涨成分股数 / 行业内有效成分股数 )
```

- 上涨判定：`close > close.shift(lookback)`（累计涨幅 > 0）。
- 有效性：`close` 或 `close.shift(lookback)` 为 NaN 的样本剔除。
- 某行业某日全员无效 → NaN（避免 0 误导）。
- 输出 value ∈ [0, 1]。

### 6.2 `diffusion_value_weighted`（自由流通市值加权）

```
扩散 = MA_smooth( 行业内上涨股自由流通市值之和 / 行业内有效股市值之和 )
```

- 在 6.1 基础上以 `free_float_mv` 加权，反映「上涨的是不是大权重股」。
- 某成分股 `free_float_mv` 缺失 → 该日该股从**分子分母双方剔除**（视作权重未知样本，比率基于剩余成分股）；如需 NaN 显式标记，调用方应在传入前自行处理 mv 缺失。
- 当所有成分股 mv 相等时退化为 `diffusion_count_ratio`。

> `membership` 是时变矩阵（每日每股一个行业名或 NaN），`_resolve_industries` 抽取去重排序的行业列表（`key=str` 兼容行业名混含 str 与数值）。

## 7. API 速查

| 函数 | 签名要点 | 返回 |
|------|---------|------|
| `equal_weight_benchmark(price)` | 各列日收益等权累乘成组合 NAV（首日=1.0）——RRG 的「行业等权组合」基准（研报 §2.1 口径）；RS-Ratio 对基准绝对水平尺度不变 | Series，index=price.index |
| `compute_rs(price, benchmark)` | RS = price/benchmark×100，含日历 ffill 兜底 | DataFrame，index=benchmark.index |
| `compute_rs_ratio(price, benchmark, lookback=220, smooth_window=20)` | RS-Ratio | DataFrame，头 239 行 NaN |
| `compute_rs_momentum(price, benchmark, lookback_ratio=220, lookback_mom=60, smooth_window=20)` | RS-Momentum | DataFrame，头 318 行 NaN |
| `compute_rrg(price, benchmark, lookback_ratio=220, lookback_mom=60, smooth_window=20)` | 一次算两者（复用中间量，推荐） | `(rs_ratio, rs_mom)` tuple |
| `diffusion_count_ratio(close, membership, lookback=220, smooth_window=20)` | 数量占比扩散 | DataFrame，columns=industry |
| `diffusion_value_weighted(close, membership, free_float_mv, lookback=220, smooth_window=20)` | 市值加权扩散 | DataFrame，columns=industry |
| `classify_quadrant(rs_ratio, rs_mom)` | 象限分类 1/2/3/4 | DataFrame（float，1/2/3/4 或 NaN） |

## 8. 使用示例

```python
# cd C-择时类/相对旋转图RRG行业轮动
from src.factor_algo import compute_rrg, classify_quadrant, diffusion_count_ratio, equal_weight_benchmark

# 1) RRG：行业价宽表 + 基准
#    研报口径基准 = 行业等权组合净值（剔综合后等权）；数据层 fetch_rrg_dataset(
#    benchmark_code="ind_avg") 已封装此构造。直接用纯函数亦可：
benchmark = equal_weight_benchmark(industry_prices.drop(columns=["801230.SI"], errors="ignore"))
rs_ratio, rs_mom = compute_rrg(industry_prices, benchmark)

# 2) 象限分类（最新一日的行业分布）
quad = classify_quadrant(rs_ratio, rs_mom)
print(quad.iloc[-1].value_counts())   # 1=领先 2=改善 3=滞后 4=疲软

# 3) 扩散指标（行业内上涨成分股占比）
diff = diffusion_count_ratio(stock_close, membership)

# 4) 绘图见《RRG绘图指南》——compute_rrg 输出可直接解包传入：
#    plot_rrg_echart(*compute_rrg(industry_prices, benchmark), shade_quadrants=True)
```
