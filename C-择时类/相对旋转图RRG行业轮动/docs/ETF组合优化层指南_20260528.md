# ETF 组合优化层指南（optimizer.py）

> 模块：`src/optimizer.py`
> 目标研报：西部证券《指数化配置系列研究（6）》§3.1–3.4
> 配套上游：行业打分来自 strategy 层 `select_diffusion_with_rrg`（phase 2）

`optimizer.py` 把**行业层信号**映射为**可交易的 ETF 组合权重**：研报 §3 用一个线性规划（LP），结合「行业打分」与「ETF 行业暴露」求解 ETF 配置权重。

---

## 1. 一句话定位与选库理由

读研报原文确认：**§3.1–3.4 是同一个 LP**，目标函数逐字相同，**只换约束集**——没有任何二次项（研报里的「跟踪误差」是结果指标，不是优化目标）。

$$\max_{w}\ \sum_{f=1}^{n} w_f \sum_{i=1}^{k} w_{f,i}\,\text{Score}_i \;=\; \max_w\ a^\top w,\qquad a = E\,s$$

- $w_f$：ETF f 的配置权重（决策变量）
- $w_{f,i}$（矩阵 E）：ETF f 对行业 i 的持仓暴露
- $\text{Score}_i$（向量 s）：行业打分（研报为 0/1）
- $a_f$：ETF f 对选中行业的总暴露

因此选 **CVXPY**（通用凸建模，一份模型 `if` 开关切四变体；§3.4 的 `|Ew−b|≤δ` 用 `cp.abs` 原生表达），而非 PyPortfolioOpt / skfolio / Riskfolio-Lib——后三者以「预期收益 + 协方差/风险度量」为核心范式，与这个**无协方差**的暴露覆盖 LP 错配（PyPortfolioOpt 的 `add_sector_constraints` 还是单一归属映射，表达不了一只 ETF 跨多行业的连续暴露）。

---

## 2. 数据契约

| 参数 | 形态 |
|------|------|
| `score` | `pd.Series`，index=industry，值 ∈ {0,1}（研报）或连续分。**选中集** = `score>0`，`k=(score>0).sum()` |
| `exposure`（E） | `pd.DataFrame`，index=etf，columns=industry，值 = $w_{f,i}$（ETF 对行业的持仓权重，行和 ≤ 1） |
| `benchmark` | `pd.Series`，index=industry，值 = 基准（沪深300）行业权重，仅 §3.4 |
| 返回 | `pd.Series`，index=etf，值 = ETF 配置权重 $w_f$ |

> **纯函数边界**：optimizer 不碰 I/O——暴露矩阵 E 由调用者/数据层（「持仓→E」，**本模块范围外**）传入。内部以 `exposure.columns` 对齐 `score`/`benchmark`，缺失行业按 0 处理。

## 3. 核心函数 `optimize_etf_weights`

```python
optimize_etf_weights(
    score, exposure, *,
    w_max=1.0,            # 单 ETF 权重上限
    gross_target=1.0,     # 仓位约束右端值
    gross_mode="eq",      # "eq"→Σw=target ; "le"→Σw≤target
    industry_cap=None,    # 每个选中行业的组合暴露上限（如 1/k）
    benchmark=None,       # §3.4 基准行业权重
    active_band=None,     # §3.4 行业偏离阈值 δ
    on_infeasible="raise",# 见 §5
) -> pd.Series            # index=etf 的权重
```

## 4. 四变体预设（推荐入口）

预设内部按 `k=(score>0).sum()` 推导约束参数，直接对应研报四节：

| 预设 | 研报 | `w_max` | 仓位 | 行业约束 |
|------|------|---------|------|----------|
| `weights_base(score, exposure)` | §3.1 | 1.0 | Σw = 1 | 每选中行业 ≤ 1/k |
| `weights_etf_capped(score, exposure)` | §3.2 | 0.2 | Σw = min(1, 0.2k) | 每选中行业 ≤ 1/k |
| `weights_unconstrained(score, exposure)` | §3.3 | 1.0 | Σw ≤ 1 | 无（退化集中到 1 只 ETF） |
| `weights_hs300_enhanced(score, exposure, benchmark, band=0.05)` | §3.4 | 1.0 | Σw = 1 | `|Ew−b| ≤ band` |

```python
from src.optimizer import weights_base, weights_etf_capped

# score 取 select_diffusion_with_rrg mask 的某换仓日一行（0/1）
w = weights_base(score, exposure)            # §3.1
w = weights_etf_capped(score, exposure)      # §3.2
```

## 5. 边界与忠实度（务必了解）

- **严格 `0<w_f` → 实现为 `w_f≥0`**：LP 求解器无法表达开区间下界；研报记法非正式，ETF 自然取 0 权重。
- **§3.3 退化集中**：删行业约束后 LP 解集中到 $a_f$ 最大的 ETF——这是研报预期行为（实测「多数时期仅持有 1–2 个 ETF」），照搬不打散。
- **`k=0`（当日无选中行业）**：返回全 0 权重 Series（合法空仓），不报错、不强行满仓。
- **不可行处理**：
  - 单日 `optimize_etf_weights`：`on_infeasible="raise"`（默认）→ 抛带 solver status 的 `ValueError`，**绝不静默返回诡异权重**；`"nan"` → 返回全 NaN Series。
  - `batch_optimize`：默认 `strict=False` 宽容——不可行换仓日返回 NaN 行 + `warnings.warn`，继续后续；`strict=True` 在第一处中断（与 `scheduler.batch` 心智一致）。
- **§3.2 仓位取等式** `Σw=min(1,0.2k)`（依公式；研报 prose 写「不超过」是宽松记法）。

## 6. 批量调用 `batch_optimize`

```python
batch_optimize(
    scores,          # DataFrame[date × industry]
    exposures,       # {换仓日: DataFrame[etf × industry]}（时变持仓）
    dates,           # 调用者指定的换仓日序列
    *, preset="base", strict=False, **preset_kwargs,
) -> pd.DataFrame    # index=dates, columns=各日 ETF 并集
```

> **禁内置「月末」逻辑**——换仓日由调用者传入（沿用算法层「日频输出、调用者采样」铁律）。`preset_kwargs` 透传给预设（如 hs300_enhanced 的 `benchmark`/`band`）。

```python
month_end = scores.index.to_series().groupby(
    [scores.index.year, scores.index.month]).max()
weights = batch_optimize(scores, exposures, month_end, preset="base")
```
