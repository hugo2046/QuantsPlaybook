# RRG 信号层指南（strategy.py + generator.py + fetch_diffusion_dataset）

> 模块：`src/strategy.py`、`src/generator.py`、`src/data_provider.py::fetch_diffusion_dataset`
> 目标研报：西部证券《指数化配置系列研究（6）》§2.1–2.3
> 下游：行业打分（boolean mask / 等权权重）喂 `optimizer.py`（见 ETF组合优化层指南）

信号层把 `factor_algo` 的 **RRG 指标 + 扩散指标** 落成研报 §2 的**三类行业轮动信号**——每类一个纯函数，输出日频 boolean mask；`RRGSignalGenerator` 把「取数 → 算指标 → 出信号」串成对外单一入口。

---

## 1. 一句话定位与分层

```
data_provider (取数)  →  factor_algo (指标)  →  strategy (选行业)  →  generator (编排)
 fetch_rrg_dataset        compute_rrg            select_by_quadrant     RRGSignalGenerator
 fetch_diffusion_dataset  diffusion_value_*      select_by_diffusion      .generate(signal)
                                                 select_diffusion_with_rrg .to_weight(mask)
```

- **strategy 层是纯函数**：DataFrame in / 日频 boolean DataFrame out，无 I/O、无月末逻辑（采样交给调用者）。
- **generator 层是轻量编排**：按 signal 的需求**惰性取数 + 缓存**，dict 派发到 strategy 函数，输出裁剪到 `[start_date, end_date]`。

研报覆盖的三类信号：

| 信号 | 研报 | 规则 | 函数 |
|------|------|------|------|
| A 纯 RRG | §2.1 | 保留指定象限的行业；若超 `top_n`，按**距中心 (100,100) 欧氏距离**取最远 `top_n` | `select_by_quadrant` |
| B 纯扩散 | §2.2 | 每日扩散指标 `top_n` | `select_by_diffusion` |
| C 扩散 + RRG | §2.3.1 | 扩散 `top_n` **先选** → 再剔除非保留象限的行业，**不补足**（剩余 ≤ `top_n`） | `select_diffusion_with_rrg` |

> ⚠️ **A 与 C 的"6 个"挑选依据不同**：A 用「距中心距离」截断，C 用「扩散排名」截断、RRG 仅作象限过滤。研报里这是两条独立策略，别混。

## 2. 数据契约

### 2.1 strategy 层（纯函数）

| 参数 | 形态 |
|------|------|
| `rs_ratio` / `rs_mom` | `pd.DataFrame`，index=date，columns=**industry_code**（`compute_rrg` 输出） |
| `diffusion` | `pd.DataFrame`，index=date，columns=**industry_code**（`diffusion_value_weighted` 输出） |
| 返回 | 同形状 `boolean DataFrame`；warm-up / NaN 当日不选 |

> **硬契约**：`diffusion.columns` 必须与 `rs_ratio.columns` 一致（均为 `industry_code`），`select_diffusion_with_rrg` 的 `diffusion & quadrant` 才能列对齐。详见 §4。

### 2.2 `fetch_diffusion_dataset`（数据层）

```python
fetch_diffusion_dataset(
    industry_codes=None,        # None=全 SW 一级
    start_date="2022-01-01", end_date="2025-12-31",
    *, lookback=220, smooth_window=20,
) -> (close, membership, free_float_mv)   # 三张 index=date × columns=stock_code 宽表
```

- `membership` 值 = **`industry_code`**（如 `801010.SI`），非 industry_name——见 §4。
- 内部把起点前移 `lookback + smooth_window` 个交易日预取 warm-up，保证扩散头部不被 `shift(lookback)` 吃空。
- `close` 取原始 `$close`；`free_float_mv` 取 `$mv`（本 qlib 后端流通市值字段，单位万 → ×10000 转元）。**注意不是 `$float_mv`**（该后端返回 0，会让扩散分母恒为 0 → 全 NaN）。
- 空数据 / 同日同股多 `industry_code`（重构期）会抛 `ValueError` / `warnings.warn`，早暴露不静默。

## 3. strategy 三信号 + 工具

```python
from src.strategy import (
    distance_from_center,        # 助手：到 (center, center) 的欧氏距离
    select_by_quadrant,          # 信号 A
    select_by_diffusion,         # 信号 B
    select_diffusion_with_rrg,   # 信号 C
)
from src.utils import to_equal_weight   # boolean mask → 等权（每行和=1，全 False → 全 0）

# 信号 A：纯 RRG，相邻 1+2 象限，距中心最远 6 个
mask_a = select_by_quadrant(rs_ratio, rs_mom, quadrants=(1, 2), top_n=6)
# 信号 B：纯扩散 top 6
mask_b = select_by_diffusion(diffusion, top_n=6)
# 信号 C：扩散 top 6 → 剔除三、四象限（保留 1/2），不补足
mask_c = select_diffusion_with_rrg(diffusion, rs_ratio, rs_mom, top_n=6, keep_quadrants=(1, 2))

weight = to_equal_weight(mask_c)
```

象限编号（`classify_quadrant`，与研报 §1 对齐）：`1=领先(>100,>100)`、`2=改善(<100,>100)`、`3=滞后(<100,<100)`、`4=疲软(>100,<100)`。

## 4. RRGSignalGenerator 编排（推荐入口）

```python
from src.generator import RRGSignalGenerator

gen = RRGSignalGenerator(
    benchmark_code="ind_avg",              # 默认：行业等权组合净值（研报 §2.1 口径）
    start_date="2022-01-01", end_date="2025-12-31",
    lookback_ratio=220, lookback_mom=60, smooth_window=20,
    benchmark_exclude=("801230.SI",),     # 等权基准剔综合；None=用全部行业
)

mask = gen.generate("diffusion_rrg", top_n=6, keep_quadrants=(1, 2))  # 信号 C
weight = gen.to_weight(mask)
```

- **RRG 基准 `benchmark_code`**：默认 `"ind_avg"`（行业等权组合净值，研报口径）；传外部指数代码（如中证 1000 `"000852.SH"`）则用外部指数为基准。`benchmark_exclude` 仅 `ind_avg` 生效，默认剔综合 `801230.SI`，`None` 用全部行业。RRG 对基准绝对水平尺度不变（仅依赖基准收益比）。
- `signal ∈ {"quadrant", "diffusion", "diffusion_rrg"}`，`**params` 透传给对应 strategy 函数。
- **按需惰性取数**：纯 `quadrant` 只取行业指数（轻）、不触发 `fetch_diffusion_dataset`（重，全成分股）；纯 `diffusion` 不算 RRG。指标缓存幂等。
- 扩散+RRG 两套指标列**无交集**时 `warnings.warn`（spec §10，早暴露 industry_code 对齐缺口）。
- 输出**裁剪到 `[start_date, end_date]`**（剔除 `fetch_diffusion_dataset` 的 warm-up 预取行），保证不同 signal 行索引一致。
- 扩展新信号 = 写一个 strategy 纯函数 + 在 `generator._SIGNALS` 注册一行 `(fn, need_rrg, need_diff)`。

## 5. 月末采样样板（调用者侧）

strategy / generator **均出日频**，月末换仓由调用者采样：

```python
def month_end_dates(index):
    s = index.to_series()
    return s.groupby([index.year, index.month]).max()

weight_month_end = weight.loc[month_end_dates(weight.index)]
```

> 各信号请按**各自 mask 的 index** 取月末——别用一个 signal 的月末日期去 `.loc` 另一个 signal（日历可能不同，会 KeyError）。

## 6. 三个绝对不能忘的边界

1. **`membership` 值必须是 `industry_code`，不是 `industry_name`**。`fetch_rrg_dataset` 的行业指数按 `code` 透视 → `rs_ratio`/`rs_mom` 列是 `industry_code`；`fetch_diffusion_dataset` 的 `membership` 值同样取 `industry_code` → `diffusion` 列也是 `industry_code`。两边一致，`select_diffusion_with_rrg` 的列对齐才成立，否则 mask 静默全 False。`factor_algo.diffusion_*` 本身对标签取值不敏感（按值分组），对齐责任在数据层。

2. **RRG 类信号有 ~318 行 warm-up 全 False**。`fetch_rrg_dataset` **不**预取 warm-up（与 `fetch_diffusion_dataset` 不对称），故窗口内前 `lookback_ratio + lookback_mom + 2*(smooth_window-1)` 行（默认 318，约 15 个月）RS 指标为 NaN → 当日全 False。若要 `start_date` 起即有 RRG 信号，把 `start_date` 提前约 318 个交易日。`diffusion` 信号无此问题。

3. **信号 C "不补足"**。扩散 top_n 先选、再剔除三/四象限后，剩余可能 < top_n（研报 §2.3.1 原样），**不会**回填到 top_n。这是特性不是 bug——实测某些月份只选出 3–5 个行业。
