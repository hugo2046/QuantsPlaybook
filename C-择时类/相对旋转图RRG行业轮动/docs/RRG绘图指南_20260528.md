# RRG 绘图指南（plotting.py）

> 模块：`src/plotting.py`
> 配套算法见《RRG算法说明_20260528.md》

`plotting.py` 提供 **RRG 轨迹双后端** + **持仓信号热力图**，三者均为**纯渲染、零 I/O**：

| 函数 | 输入 | 后端 | 返回 | 适用 |
|------|------|------|------|------|
| `plot_rrg_chart` | `compute_rrg` 的 `(rs_ratio, rs_momentum)` | matplotlib | `None`（可 `save_path` 存图） | 静态图 / 研报截图 / 批量导出 |
| `plot_rrg_echart` | 同上 | pyecharts | `pyecharts.Line` | 交互图 / jupyter / hover 看明细 |
| `plot_signal_heatmap` | `score_panel`（0/1 持仓面板） | pyecharts | `pyecharts.HeatMap` | 行业×日期持仓信号一览 / 换仓审计 |

> 前两者是 RRG 散点轨迹（§1–§7）；`plot_signal_heatmap` 是另一类图（信号面板热力图，见 §8），输入契约不同——它吃信号层 `select_*` / `RRGSignalGenerator.generate` 出的 0/1 mask，不吃 RRG 指标。

> ⚠️ **图空白排查（与操作系统无关，两个根因）**：
> 1. **echarts CDN 加载失败（最常见）**：pyecharts 默认 `assets.pyecharts.org` 常证书过期/不可达 → echarts.min.js 取不到 → `render()` 文件、`render_notebook()`、notebook 全空白（浏览器打开 html 也黑屏即此症）。**本模块 import 时已自动把 `CurrentConfig.ONLINE_HOST` 切到稳定的 jsdelivr**，故经 `plotting.py` 出的图各渲染路径默认就用可用 CDN；旧的空白 html 重新 `render()` 即可。China 网络若 jsdelivr 受限，调用前 `from pyecharts.globals import CurrentConfig; CurrentConfig.ONLINE_HOST="https://cdn.bootcdn.net/ajax/libs/echarts/5.4.3/"`。
> 2. **VS Code notebook 的 RequireJS 缺失**：`chart.render_notebook()` 默认用 `require(['echarts'])`，VS Code 渲染器无全局 `require` → 静默空白（cell 0.0s ✓）。**改用 `render_in_notebook(chart)`**（本模块助手，render_embed → base64 data-uri iframe，对所有 pyecharts 图通用，且默认走 jsdelivr 一并解上面第 1 条）。经典 Jupyter 下 `render_notebook()` 仍可用。

## 1. 统一签名前导块

两后端的签名**前导块完全一致**（同名 / 同序 / 同默认 / 同 kind），调用者在两后端间切换零心智负担：

```python
plot_rrg_xxx(
    rs_ratio, rs_momentum, *,
    tail_length=None,        # 显示点尾迹长度
    step=1,                  # 显示点抽稀步长
    center=(100, 100),       # 象限十字中枢
    symmetric=False,         # 轴对称延展
    shade_quadrants=False,   # 四象限着色 + 角落标签
    show_grid=True,          # 网格
    ...后端特有参数...
)
```

> 数据参数 `rs_ratio, rs_momentum` 为位置-or-关键字；其后全部 **keyword-only**（`*`），防共有参数多时位置传参错位。
> `compute_rrg` 输出可直接解包：`plot_rrg_echart(*compute_rrg(price, bench), shade_quadrants=True)`。

## 2. 共有参数详解

| 参数 | 默认 | 说明 |
|------|------|------|
| `tail_length` | `None` | 仅画每行业最后 N 个**显示点**（None/≤0=全量）。在 `step` 抽稀**之后**生效——覆盖 `tail_length × step` 个交易日。 |
| `step` | `1` | 显示点抽稀步长。`1`=日频全画；`>1` 时锚定最新日向前每 step 个交易日取一个显示点。 |
| `center` | `(100, 100)` | 象限分隔与着色的中枢，固定 (100,100) 与 `classify_quadrant` 对齐。 |
| `symmetric` | `False` | `True` 时强制 x/y 轴以 `center` 为几何中心对称延展，半径 `max(|v−center|)×1.05`；`False` 走 `floor(min×0.9)/ceil(max×1.1)`。 |
| `shade_quadrants` | `False` | `True` 时填充四象限淡色背景（alpha=0.08）+ 四角落标签（领先/改善/滞后/疲软）。 |
| `show_grid` | `True` | 是否显示网格。与 `shade_quadrants=True` 配合时建议 `False`，更贴近研报图 2。 |

### 2.1 step 降采样原理（关键）

日频 RRG 经 MA(`smooth_window`=20) 平滑后，**相邻交易日的点距极小**（实测 ~0.48），全画会挤成一团。研报图 2 标注「频率 d」但点拉得开——它是在**日频序列上按周采样显示点**（stockcharts RRG 的标准做法：日频计算、周频显示尾迹）。

| step | 相邻显示点平均距离 | 20 点尾迹覆盖 |
|------|------------------|--------------|
| 1（每日） | 0.48（挤成团） | ~20 交易日 |
| **5（≈周）** | **2.35（拉开 ~5×）** | **~100 交易日** |
| 10（双周） | 4.58 | ~200 交易日 |

抽稀**锚定最新日**（`_subsample_tail`：反转→每 step 取一→再反转），保证「今天」恒在显示点内。`step` 是显示层手段，**不改算法**（`smooth_window`/`lookback` 是研报指定的因子语义，勿动）。

## 4. 四象限视觉协议

两后端共用模块级 `_QUADRANT_HEX` 调色板（单一事实源，配色严格一致）：

| 象限 | 位置 | 颜色 | hex |
|------|------|------|-----|
| 领先 | 右上 | 绿 | `#38b48b` |
| 改善 | 左上 | 蓝灰 | `#44617b` |
| 滞后 | 左下 | 橙 | `#bf783a` |
| 疲软 | 右下 | 紫 | `#745399` |

`shade_quadrants=True` 时：mpl 用 `Rectangle(alpha=0.08)` + 角落 `text`；echart 用 `MarkAreaItem`（`_hex_to_rgba(hex, 0.08)` 填充 + `insideTopRight/...` 角落标签）。

> echart 的 markArea 是 series-scoped overlay——只挂在第一个有效 series 上（避免 N 个 series 叠加把 alpha=0.08 累成 81% 不透明盖死轨迹）。

`plot_rrg_echart` 默认 `trigger="item"`，hover 单个数据点显示五行明细（圆角白底 + 浅蓝边框）：

```
标签：<行业名>

相对强弱动量：<RS-Mom − center>

```

## 7. 边界与健壮性

- **全 NaN / 空有效值输入**：两后端轴边界都有兜底（`_axis_bounds` / `_symmetric_radius` 先滤 finite，空则退回 `center±5`），不会 `math.floor(nan)` 崩溃。
- **`tail_length=0` / 负数**：等价 `None`（全量），`_subsample_tail` 的 `> 0` 守卫安全跳过。
- **`step≤1`**：不抽稀（向后兼容）。
- **rs_ratio / rs_momentum 行列不一致**：内部先 `align`，按交集绘制。
- **中文字体**：mpl 路径依赖 `SimHei`（模块顶部已设 `font.sans-serif`）；缺字体时会有 `findfont` 噪声但不崩溃。

## 8. 持仓信号热力图 `plot_signal_heatmap`

把信号层出的 **0/1 持仓面板**渲染成「行业 × 日期」热力图——一眼看清每个换仓日哪些行业被选中（红）、哪些空仓（灰），适合换仓审计与信号节奏复盘。

### 8.1 输入契约

| 参数 | 形态 |
|------|------|
| `score_panel` | `pd.DataFrame`，index=date，columns=申万一级行业**代码**（如 `801080.SI`），value ∈ {0, 1}（`NaN` 当 0 处理） |
| `code2name` | `dict[str, str]` 行业代码→中文简称；`None` 或缺某列时该行业 y 轴标签**回退用原代码** |

> `score_panel` 正是 `RRGSignalGenerator.generate(...)` → 月末采样 `.loc[me]` 的输出（index=换仓日，columns=行业代码）。

### 8.2 后端特有参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `title` | `"行业轮动持仓信号"` | 图标题。 |
| `held_color` | `"#c23531"`（研报红） | 持仓（value=1）格颜色。 |
| `empty_color` | `"#eeeeee"`（浅灰） | 空仓（value=0）格颜色。 |
| `date_fmt` | `"%Y-%m-%d"` | x 轴日期 `strftime` 格式。 |
| `width` / `height` | `"1280px"` / `"720px"` | 画布尺寸。 |
| `bg_color` | `"white"` | 画布背景（防 jupyter 暗主题反色，与 RRG 图一致）。 |

### 8.3 关键设计

- **零 I/O 纯渲染**：`code2name` 由调用方传入，本函数不取数——与 `plot_rrg_echart` 吃 DataFrame 同构。最便捷的 `code2name` 来源是 **`RRGSignalGenerator.code2name`**（`generate` 时已取数缓存，零额外 DB 调用），或 `fetch_rrg_dataset(...)[2]`。
- **piecewise visualMap**：0/1 离散两段直接映射灰/红（`pieces=[{value:1,红},{value:0,灰}]`），比连续 visualMap 更贴二元持仓语义——不会在 0、1 间插值出中间色。
- **tooltip 注入数组**：hover 显示「行业 / 日期 / 持仓·空仓」。heatmap 数据项是 `[xIdx, yIdx, value]` 数值索引，`p.name` 语义跨 echarts 版本不稳，故把日期/行业名两数组以 JSON 字面量注入 JsCode、按索引取回标签（与 `_rrg_tooltip_formatter` 注入 center 同款手法）。

### 8.4 用法（接信号层）

```python
from src.generator import RRGSignalGenerator
from src.plotting import plot_signal_heatmap

gen = RRGSignalGenerator(start_date=start_date, end_date=end_date)
mask = gen.generate("diffusion_rrg", top_n=6, keep_quadrants=(1, 2), exclude=["801230.SI"])
me = month_end_dates(mask.index)
me = me[me >= pd.Timestamp(backtest_start)]
score_panel = mask.loc[me].astype(float)

# code2name 直接从 gen 取（generate 已取数，零额外 DB 调用）
from src.plotting import render_in_notebook
chart = plot_signal_heatmap(score_panel, code2name=gen.code2name)
render_in_notebook(chart)            # VS Code 稳健渲染（或 chart.render("signal_heatmap.html")）
```

> `RRGSignalGenerator.code2name` 是配套新增的属性——首次访问惰性触发 RRG 取数（若 `generate` 已跑则零成本命中），把行业代码列转中文标签的唯一桥。
