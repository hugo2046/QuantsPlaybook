# 相对旋转图 RRG 行业轮动（ETF 纯离线版）

基于西部证券《指数化配置系列研究（6）：相对旋转图 RRG 框架下的行业研究》的复现项目：
RS-Ratio / RS-Momentum 双轴 RRG 行业轮动信号 → 中信/申万一级行业 → 代表 ETF 映射 →
组合优化（含 cap）→ vectorbt 回测与持仓暴露分析。本项目为**纯离线快照迁移版**——
从源研究工程剥离全部在线数据依赖（数据库 / 行情 API），仅凭 `data/etf_rrg.duckdb`
单文件快照即可完成信号计算与回测。

## ⚠️ 复现范围与已知偏离（务必先读）

本项目**忠实复现研报的方法**——RRG 公式、扩散指标、LP 优化、回测口径逐条对齐，
行业等权基准分年度与研报吻合到小数点后两位。但**回测数字不等同研报**（原因见下）。
**请当作「研报方法的可复现实现 + 教学 demo」，不要当作可直接使用的策略或已验证的 alpha。**

**与研报绩效对照**（研报 2018.12.28–2026.03.31 全窗口 vs 本项目 2022.09–2026.08 中信臂）：

| 策略 | 研报 年化 / 夏普 / 最大回撤 | 本项目 年化 / 夏普 / 最大回撤 |
|------|------|------|
| ETF 轮动 base（每行业 ≤ 1/k） | 21.51% / 0.80 / −34.98% | 19.9% / 0.67 / −17.8% |
| ETF 轮动 unconstrained（无行业上限） | 31.53% / ~1.0 / −33.33% | 21.9% / 0.78 / −34.9% |

> base 层接近（年化差约 1.6pp；本项目回撤更小是因窗口避开 2022 大熊）；unconstrained 层
> 研报明显更高（年化差约 10pp），差距主要来自窗口 + 数据口径。

**已知偏离（为什么对不上）：**

1. **回测窗口更短**：研报 7.3 年（含 2019 +47%、2020 +49% 两年大牛）；本快照数据自 2019-11 起、
   notebook 回测自 2022-09 起，天然少了弹性最高的两年。
2. **扩散指标用流通市值，非自由流通市值**：研报 §2.2 用自由流通市值加权；快照 `$mv` 是流通市值
   （工行等国企流通市值 ≫ 自由流通），银行/石化/煤炭等行业的扩散被少数大票主导。tushare 无自由
   流通字段，无法就地修。
3. **ETF 暴露矩阵一年约 8 个月只见前十大持仓**：A 股基金 Q1/Q3 季报仅披露前十大重仓（合计常
   40–70%），仅半年报/年报 ≈ 全持仓。研报「全部持仓」很可能用 PCF 申赎清单（每日全持仓），
   `fund_portfolio` 给不了 → 换仓日暴露矩阵 `E_t` 行和约 0.5、行业上限约束半失效。
4. **生存偏差**：`fetch_etf_meta(only_listed=True)` 只保留在售 ETF，退市 ETF 未纳入快照。
5. **候选池口径**：研报限「行业和主题 ETF」；本实现取全部非 QDII ETF 靠打分剔除，`etf_meta` 无
   行业/主题标签，无法严格按研报口径筛。

其中 2 / 3 / 5 是数据源先天局限，需换 PCF 全持仓 + 自由流通市值字段才能治本；在现有
tushare / 快照口径下本项目已做到方法忠实。回测执行口径：换仓日收盘出信号、**次日开盘成交**
（无日内前视），年化按 252 交易日。

## 离线运行三步

1. 环境：conda base（Python 3.10+），安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 数据：从百度网盘下载 `etf_rrg.duckdb`（约 1.1G+，见 `data/说明.md` 的下载链接），
   放到 `data/` 目录下。
3. 运行：用 Jupyter 打开并执行
   [`notebook/etf_rrg.ipynb`](notebook/etf_rrg.ipynb)
   （中信体系全流程：信号 → ETF 组合优化 → 回测报表 → 绘图）。

跑测试（合成数据，无需快照）：

```bash
python -m pytest tests/ -q
```

## 离线限制

- RRG 基准仅支持 `benchmark_code='ind_avg'`（行业等权基准）。外部指数基准
  （如中证 1000 `000852.SH`）需联网取数，未纳入快照，请求时抛 `OfflineDataError`。
- 请求窗口超出快照覆盖（行业日线 / 行业成分 / 个股行情任一缺口）时 fail-loud
  抛 `OfflineDataError`，不做静默补数或插值。
- 快照 schema、单位（元）与各表说明详见 [`data/说明.md`](data/说明.md)。

## 目录结构

```
├── src/                    # 计算与数据读取层（import 路径均为 src.X）
│   ├── factor_algo.py      # RRG / 扩散指标纯计算（RS、动量、象限、扩散加权）
│   ├── generator.py        # RRGSignalGenerator 编排（信号层入口）
│   ├── strategy.py         # 象限 → 目标行业策略
│   ├── optimizer.py        # ETF 组合优化（cvxpy：等权 / capped / 行业上限）
│   ├── backtest.py         # 暴露面板、代表 ETF 池、vectorbt 回测、报表
│   ├── exposure.py         # ETF 真实持仓 → 行业暴露矩阵
│   ├── plotting.py         # RRG 图 / 持仓热力图（matplotlib + pyecharts）
│   ├── store.py            # DuckDB 缓存（持仓 / 行业成分，miss 抛 OfflineDataError）
│   ├── data_provider.py    # 离线只读取数层（快照 reader + 联网 guard）
│   └── utils.py
├── tests/                  # 合成数据测试套件（离线，零外部依赖）
├── notebook/               # zx 全流程 notebook
├── data/                   # 快照 duckdb（网盘下载）+ ETF↔行业映射小文件
├── docs/                   # 算法与各层指南文档
└── requirements.txt
```
