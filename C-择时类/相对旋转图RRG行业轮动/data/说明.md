# ETF-RRG 离线快照数据说明

本项目为**纯离线**迁移：所有计算与回测仅凭本目录下的 `etf_rrg.duckdb` 单文件快照完成，
不连接任何数据库或行情 API。缺数据时相关函数抛 `OfflineDataError`（fail-loud）。

## 离线限制

- RRG 基准仅支持 `benchmark_code='ind_avg'`（行业等权基准）；外部指数基准（如
  `000852.SH`）需联网取数，未纳入快照，请求时抛 `OfflineDataError`。
- 请求的时间窗若超出快照覆盖范围（行业日线 / 成分 / 个股行情任一缺口），同样
  fail-loud 抛 `OfflineDataError`，提示快照窗口不足。
- `etf_portfolio`（ETF 季度持仓）与 `sw_membership` / `zx_membership`（行业成分）
  为**随快照物化的缓存**：命中 coverage 直接读库；miss 时触发联网 guard 抛
  `OfflineDataError`（离线不补数）。

## 快照 Schema（DuckDB 单文件 `etf_rrg.duckdb`）

已有缓存表（源项目 `store._init_schema` 建，随快照分发）：

| 表 | 列 | 主键 |
|----|----|------|
| `etf_portfolio` | code TEXT, symbol TEXT, ann_date DATE, end_date DATE, mkv DOUBLE, amount DOUBLE, stk_mkv_ratio DOUBLE, stk_float_ratio DOUBLE | (code, end_date, symbol) |
| `etf_portfolio_coverage` | code TEXT, period DATE, fetched_at TIMESTAMP | (code, period) |
| `sw_membership` | trade_date DATE, stock_code TEXT, industry_code TEXT | (trade_date, stock_code) |
| `sw_membership_coverage` | id INTEGER, min_date DATE, max_date DATE, fetched_at TIMESTAMP | id |
| `zx_membership` | trade_date DATE, stock_code TEXT, industry_code TEXT | (trade_date, stock_code) |
| `zx_membership_coverage` | id INTEGER, min_date DATE, max_date DATE, fetched_at TIMESTAMP | id |

导出物化表（`export_snapshot.py` 填充）：

| 表 | 列 | 主键 | 单位/说明 |
|----|----|------|-----------|
| `trade_days` | trade_date DATE | (trade_date) | 快照跨度内全部交易日 |
| `sw_industry_daily` | trade_date DATE, code TEXT, industry_name TEXT, close DOUBLE, open DOUBLE | (trade_date, code) | 申万一级行业指数日线 |
| `zx_industry_daily` | trade_date DATE, code TEXT, industry_name TEXT, close DOUBLE, open DOUBLE | (trade_date, code) | 中信一级行业指数日线 |
| `etf_daily` | date DATE, code TEXT, adjclose DOUBLE, adjopen DOUBLE, amount DOUBLE | (date, code) | amount 已 ×1000 转**元** |
| `etf_meta` | ts_code TEXT, index_code TEXT, index_name TEXT, list_date TEXT, list_status TEXT, etf_type TEXT, setup_date TEXT, mgt_fee DOUBLE | (ts_code) | 原始 etf_basic 字段；日期为 YYYYMMDD 文本 |
| `ashares_close` | date DATE, stock_code TEXT, close DOUBLE | (date, stock_code) | 成分股收盘价（窗口内曾为成分者） |
| `ashares_float_mv` | date DATE, stock_code TEXT, float_mv DOUBLE | (date, stock_code) | 当日**流通市值**（源 `$mv`，非自由流通市值），已 ×10000 转**元**。⚠️ 研报 §2.2 扩散指标用自由流通市值加权，本快照用流通市值——已知口径偏离 |

单位约定：所有金额/市值类字段统一为**元**（`etf_daily.amount` 导出时已从千元 ×1000，
`ashares_float_mv.float_mv` 已从万元 ×10000）。

- `etf_sw_mapping.csv` / `etf_sw_mapping_dynamic.csv` / `etf_sw_mapping_reconciled.csv`：
  ETF → 申万一级行业映射（静态 / 动态 / 对账三版本，notebook 与暴露层使用）。
- `ETF基础信息.xlsx`：ETF 基础信息表（人工核对参考）。

`etf_rrg.duckdb`（及任何 `.wal` 文件）**不入 git**，仅经网盘分发。
